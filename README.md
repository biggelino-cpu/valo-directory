# VALO DIRECTORY

Independent, curated catalog of Valorant trackers, lineup sites, overlays, bots, and community tools. We list and link — we do not host the tools.

VALO DIRECTORY is not affiliated with, endorsed, sponsored or approved by Riot Games, Inc. VALORANT and related marks are property of Riot Games, Inc.

## Stack

- TanStack Start + Vite
- Tailwind CSS
- PGLite for shared submissions

## Run

```bash
npm install
npm run dev
```

## Catalog

Seed listings live in `src/lib/tools/seed.ts`. Community submissions go through `/submit` and wait for review at `/review` (review key required).
